## 🚀 BlazeAI - AI-Powered Salesforce Development

BlazeAI is an intelligent development assistant that leverages Claude Code SDK to accelerate Salesforce development with AI-powered code generation, real-time deployment, and multi-org support.

## 📦 Download Latest Release

Visit the [Releases](https://github.com/igness-ai/blaze/releases/latest) page to download the latest version.

### System Requirements

- **macOS**: 10.14 or later (Intel & Apple Silicon)
- **Windows**: 10 or later (64-bit)
- **RAM**: 8GB minimum, 16GB recommended
- **Storage**: 2GB available space

## 🎯 Key Features

- **AI-Powered Development**: Leverage Claude Code SDK for intelligent code generation
- **Multi-Org Support**: Seamlessly switch between Salesforce organizations
- **Real-Time Deployment**: Deploy code directly from the assistant
- **Conversation History**: SQLite-based persistent conversation storage
- **Secure Authentication**: AWS Cognito-based authentication system

## 📥 Installation

### macOS
1. Download the `.dmg` file from the [latest release](https://github.com/igness-ai/blaze/releases/latest)
2. Open the DMG file
3. Drag Blaze to your Applications folder
4. On first launch, right-click and select "Open" to bypass Gatekeeper

### Windows
1. Download the `.exe` installer from the [latest release](https://github.com/igness-ai/blaze/releases/latest)
2. Run the installer
3. Follow the installation wizard

## 🔒 Security

- **Code Signing**: All macOS builds are signed and notarized by Apple
- **Secure Storage**: Credentials are stored securely using system keychain
- **JWT Authentication**: Industry-standard authentication protocols
- **No Source Code**: This repository contains only compiled binaries
